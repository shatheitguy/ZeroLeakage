Devices

Name your LAN devices by IP, or link phones and PCs running the ZeroLeakage app so they're protected on mobile data too.

Add a device

Leave IPs empty for a phone or laptop: it gets its own DoH URL and Private DNS hostname.

Pairing code

In the app: Profile → Account & sync → Connect to server → Pairing code. One use, valid 10 minutes. No password on the phone.

Link the app

In the ZeroLeakage app open Profile → Account & sync → Connect to server and paste this code. It's shown once.

Flood: queries/second. NXDOMAIN: distinct non-existent names. Tunnel: distinct random-looking subdomains of one domain. Infected: malware/phishing lookups. Brute force: failed sign-ins.

DNS feeds block answers that point at known-bad addresses ("Malicious IP" in the log). Attacker feeds (scanners, brute-forcers) are meant for your firewall.

Under the hood · Android

A firewall that never sees your traffic.

Only DNS is routed through the on-device tunnel, so browsing, streaming and calls never pass through it, and battery use stays low.

Intercept

Apps ask the virtual DNS server inside a local VPN. Nothing leaves the phone yet.

Attribute

Android tells us which app owns the socket, so every query has a name.

Decide

Blocklists, per-app rules and the current mode decide: allow, block or ask.

Encrypt

Allowed lookups go out over DoH. Blocked ones get an instant NXDOMAIN.
